# Technology fingerprint dataset

`categories.json` and `technologies/*.json` are the **webappanalyzer** technology
fingerprint dataset, the community-maintained open-source fork of Wappalyzer's data.

- Source: https://github.com/enthec/webappanalyzer
- License: **GNU GPL v3.0** (see `LICENSE` in this folder)

The data is bundled verbatim and used only to identify web technologies on pages the
user explicitly runs the tech profiler on. It is **not** the proprietary Wappalyzer
dataset. The YoshTool matching engine (`tech-core.js`) is an independent reimplementation.
