Cookie

Hanya domain pada daftar ini yang bisa diekspor/diimpor cookie-nya. Tombol di bawah akan menampilkan dialog izin bawaan Chrome untuk domain tab aktif.

    Auto-sensor (mode privasi)

    Menutup (blur) data sensitif di halaman secara langsung saat browsing — untuk proteksi screen-share. Daftar ini terpisah dari Cookie: menambah domain di sini TIDAK mengizinkan ekspor cookie-nya.

      Screenshot: hasil disalin ke clipboard secara default. Centang kotak di bawah untuk menyimpan sebagai berkas (dialog Simpan akan muncul).

      Blur bisa dipulihkan — untuk data sangat sensitif pakai Solid.

      Popup blocker

      Blokir popup/popunder (window.open) di semua situs. Butuh izin akses semua situs — diminta lewat tombol ini (dialog Chrome), bukan saat instal.

      Setiap window.open yang diblok menampilkan bar (Izinkan / Latar / Alihkan / Percaya / Blokir). Host OAuth & pembayaran umum sudah di-whitelist default.
